# Forword — App-first publishing platform

A premium, mobile-first reading experience for articles, short stories and short novels.

## Stack
- React + TypeScript + Vite
- Responsive app-shell UI with mobile bottom navigation
- Supabase backend integration planned

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Next milestones
1. Supabase Auth, profiles, content schema and Row Level Security.
2. Real routes for feed, article, short story, novel/chapter, author and profile.
3. Editor, draft/publish workflow, comments, likes, bookmarks and follows.
4. Server rendering/prerendering for public content, dynamic sitemap, robots.txt, canonical tags and JSON-LD.
5. Vercel deployment and custom domain configuration.

Current UI uses demonstration content and does not yet persist data or authenticate users.
